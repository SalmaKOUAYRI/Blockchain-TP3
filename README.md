# Blockchain TP3
Personal project about Bitcoin and Blockchain technology
Blockchain TP3 – Bitcoin Transaction Analysis

1. Project Topic

This project focuses on understanding Bitcoin blockchain technology and analyzing a Bitcoin transaction.

2. Objectives

* Understand how Bitcoin transactions work.
* Identify transaction inputs and outputs.
* Understand transaction fees.
* Explain confirmations and UTXO.

3. Methodology

The project uses a practical and documentary approach based on Bitcoin TestNet4.

4. Expected Results

Understand the structure of a Bitcoin transaction and the role of blockchain technology.

5. Tools Used

* GitHub
* GitHub Desktop
* Bitcoin TestNet4
* AI assistant for guidance.
